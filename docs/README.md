## 简介

CMY 启动器（梦之韵Pro）是由梦之韵团队基于 [HMCL](https://github.com/huanghongxun/HMCL) 开源开发版二次开发的 Minecraft 启动器。

本仓库为**合规开源仓库**，仅包含源代码，不包含构建产物和发布流程。

## 功能特性

- 多实例管理
- 云端自动更新
- 梦之韵整合包一键下载
- 国内网络优化
- 樱花粉自定义主题
- 内置 Java 运行时（完整包）

## 下载

请访问 [官网](https://www.camzy.tech) 或 [发布页](https://github.com/maoxinhe/mzy-pro-source/releases) 下载最新版本。

## 构建

```bash
./gradlew :HMCL:shadowJar
```
